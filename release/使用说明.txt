Sora V2 电量托盘 · v1.3.0

本版本仅保留 Ninjutso Sora V2。

1. 更新前先退出旧版。将 ZIP 解压到固定位置，再双击带版本号的 EXE。
2. 插入 Sora V2 接收器或连接 USB 线，检测到连接后才显示设备卡片和电量托盘图标。
3. 托盘直接显示 0–100 的完整数字，悬停查看状态；绿色为充电，低电量为红色。
4. 每 2 秒检查插拔；正常电量查询按设置的 30 秒、1 分钟、2 分钟或 5 分钟执行。
5. 接收器已插入而鼠标休眠时，设备保留，未知电量显示 --。可唤醒后刷新。
6. 关闭面板继续后台监控；再次双击 EXE 或托盘图标打开面板，面板「退出」完全退出。
7. 面板支持低电量阈值、通知、开机启动、连接排查和导出诊断。

运行环境：标准 Windows 10/11，系统自带 .NET Framework 4.6 或更高版本。
无需 Python、第三方 HID DLL 或另行安装 .NET 8。此 EXE 不能直接运行于 macOS/Linux。

匹配范围：VID 1915，接收器 PID AE1C / 有线 PID AE11，Usage Page FFA0。
只查询 Sora V2；其他设备不会识别和读取。固件或接收器变体可能需要适配。
当前按一只 Sora V2 设计；多个同型号设备取第一个有效读数。

无读数时，先移动鼠标唤醒，关闭 Ninjutso 官方软件/网页驱动，再刷新或重新插拔。
本机设置、日志和诊断位于 %LOCALAPPDATA%\MouseBatteryTrayNative，不自动上传。
卸载前先关闭开机启动并退出程序，再删除程序和设置目录。

验证：35 项协议、插拔及数字绘制测试通过，C# 5/.NET Framework 4.6 编译通过。
